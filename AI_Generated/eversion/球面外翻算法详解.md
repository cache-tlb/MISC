# 把球面翻个面：Thurston 球面外翻算法详解

> 想象一个橡皮球，红色朝外、青色朝内。能不能在**不撕破、不捏出折痕、允许自己穿过自己**的前提下，把它连续地翻成青色朝外？
>
> 直觉会喊"不可能"。但 1958 年 Stephen Smale 证明了它**一定**可以，只是他的证明没给出具体动作。三十多年后，Bill Thurston 的"波纹法（corrugation）"给出了一套能真正画出来的做法，被 Nathaniel Thurston 写进了程序 `evert`，并拍成了著名短片 *Outside In*（1994）。

这篇文章拆解这套算法：先讲清楚"翻面"和"折痕"到底是什么，再用一个一维的小例子说明为什么"圆圈翻不过来"、而球面却可以；然后讲波纹为什么能消除折痕；最后落到代码，看它是怎么用一种叫 **jet（自动微分）** 的技巧把曲面法线精确算出来的。全程只用到高中/大一的求导，理科生可以跟着一步步推。

配套的 WebGL demo 就是本文算法的实现，文末附了实时截图。

## 一、先把"翻面"和"折痕"说清楚

我们把球面看成一张**参数曲面**：给两个参数 $u$（纬度）、$v$（经度），返回空间中一个点

$$
\mathbf P(u,v)=\big(x(u,v),\,y(u,v),\,z(u,v)\big).
$$

在每个点上，沿两个参数方向各求一次偏导，得到两个**切向量**：

$$
\mathbf P_u=\frac{\partial \mathbf P}{\partial u},\qquad
\mathbf P_v=\frac{\partial \mathbf P}{\partial v}.
$$

它们张成这一点的**切平面**。切平面的法线就是两者的叉积：

$$
\mathbf N=\mathbf P_u\times\mathbf P_v=
\begin{pmatrix}
y_u z_v-z_u y_v\\[2pt]
z_u x_v-x_u z_v\\[2pt]
x_u y_v-y_u x_v
\end{pmatrix}.
$$

（下标表示偏导，例如 $y_u=\partial y/\partial u$。这个分量式待会儿会**一字不差**地出现在代码里。）

叉积的长度等于 $\mathbf P_u,\mathbf P_v$ 张成的平行四边形面积。于是有一个干净的判据：

$$
\mathbf N\neq\mathbf 0
\iff
\mathbf P_u,\mathbf P_v\ \text{线性无关}
\iff
\text{这一点有确定的切平面}.
$$

数学上，处处满足 $\mathbf N\neq\mathbf 0$ 的映射叫做**浸入（immersion）**。反过来，$\mathbf N=\mathbf 0$ 的地方，两个切向量挤到了一条线上（或缩成零），切平面塌陷——这就是我们要极力避免的**折痕 / 尖点 / 夹点**这一类**奇点**。

> **一个极其关键、但常被误解的点：**"允许自己穿过自己"和"折痕"是两回事。
>
> 浸入**不要求**曲面是嵌入的——它完全**允许曲面与自身相交**（就像两张纸互相穿过，每张纸在交线处各自都还是平整的，切平面都好好的）。外翻过程中球面确实会大面积地穿过自己，这**没问题**。真正被禁止的，只有"某一点的切平面塌陷（$\mathbf N=\mathbf 0$，微分降秩）"这种**奇点**。
>
> 所以本文说的"没有折痕"，精确含义是：**整个变形过程中，每一点、每一时刻都保持 $\mathbf N\neq\mathbf 0$。**

于是"外翻"可以被精确地定义为：一条从"红朝外的球"到"青朝外的球（法线整体反向）"的连续变形，并且**每一个中间时刻都是浸入**。这种"全程保持浸入"的连续变形有个专门名字——**正则同伦（regular homotopy）**。（严格来说，还要求切映射 $\mathrm d\mathbf P_t$ 随时间连续变化，而不只是每一帧碰巧是浸入。）

## 二、一维热身：为什么"圆圈"翻不过来

球面的问题不好直接想象，先把维度降一维：平面上的**闭曲线**能不能"翻面"？

给闭曲线一个走向，它在每一点有单位切向量 $\mathbf T(s)$。当你绕曲线走一圈回到起点，切向量的方向 $\theta(s)$ 会累计转过若干整圈。转过的圈数叫**转数（turning number）**：

$$
\text{转数}=\frac{1}{2\pi}\oint \mathrm d\theta \in \mathbb Z.
$$

- 一个**逆时针**的标准圆：切向量正好逆时针转一整圈，转数 $=+1$。
- 同一个圆，改成**顺时针**走：转数 $=-1$。

**Whitney–Graustein 定理（1937）** 说：平面上两条闭曲线能通过"全程保持处处速度非零（浸入）"的连续变形互相变到，**当且仅当**它们转数相等。

转数是整数，中途不能连续地从 $+1$ 跳到 $-1$。要强行把它从 $+1$ 变成 $-1$，中途某一时刻必然出现 $\mathbf T$ 无定义的点——也就是曲线速度为零的**尖点**（一维版的"折痕"）。所以：

> **在平面里，圆圈翻不过来。** 障碍就是那个整数转数 $+1\neq-1$。

请记住这个结论——它会反衬出三维情形有多反直觉。

## 三、三维里的奇迹：多一个维度，障碍消失了

现在回到球面。二维球面 $S^2$ 嵌在三维空间 $\mathbb R^3$ 里，"翻面"要求把朝外的法线连续地变成朝内的。按一维的经验，你会预期也有个"整数障碍"挡着。

**Smale 定理**（1957 年宣布，1959 年发表于 *Trans. AMS*）却给出了惊人的结论：

> $\mathbb R^3$ 中 $S^2$ 的所有浸入，在正则同伦下**只有一个类**。

只有一个类，意味着"红朝外的球"和"青朝外的球"落在同一类里——它们之间**存在**一条全程保持浸入的连续变形。球面外翻**必然可行**。当年这个推论一出来，很多人第一反应是不敢相信。

为什么一维卡死、三维却放行？直观说法是：**多出来的那一维给了切标架旋转的余地**，一维里转不过去的方向，三维里可以"绕着侧面转过去"。

> **更严格一点**（想深究的读者看，其余可略过）：一维的障碍来自 $\pi_1\big(SO(2)\big)=\mathbb Z$——旋转群 $SO(2)$ 是个圆，绕它走的圈数就是那个转数。而二维球面的对应障碍住在 $\pi_2\big(SO(3)\big)=0$——它是**平凡群**，没有非零元素可当障碍。障碍群从 $\mathbb Z$ 变成 $0$，这才是"障碍消失"的本质。

麻烦在于，Smale 的证明是**存在性**的、不构造的：它告诉你路径存在，却不画给你看。把这条抽象路径变成一段能看的动画，花了后人几十年。Thurston 的**波纹法**就是其中一种做法。

## 四、关键武器：波纹（corrugation）与 8 字形截面

### 4.1 为什么要打波纹

设想最"莽"的做法：把北极按着，直接怼穿南极。到两极相遇的一刹那，上下两片膜的切平面正好重合、方向相反，$\mathbf N$ 抵消为零——**啪，一个夹点（折痕）**。这正是要避免的奇点。

Thurston 的思路是：先在球面上**打上一圈一圈的波纹**（想想水母裙边、灯笼的褶、螺纹管的纹路）。这些波纹沿着"运动方向"排布，给曲面提供**横向的余量**。有了余量，当两片膜要相互穿过时，膜可以"侧着身子、带着褶皱"平滑地穿过去，切向量 $\mathbf P_u,\mathbf P_v$ 始终保持线性无关——**法线只是转了转方向，never 归零**。翻完之后，再把波纹平滑地抹掉。

一个**重要的界定**：波纹法并不是"随便什么变形都能这样救活"。它是**h-原理**的一个实现——只有当两端本来就（形式上）正则同伦时，加波纹才能把一条普通的连续变形升级成正则同伦。它提供的是**局部**的浸入自由度，绕不过**全局**障碍。对球面来说，正是 Smale 定理保证了那个全局障碍为零，波纹法才用得上。（这也是为什么它救不了平面上的圆——那儿的障碍 $+1\neq-1$ 并没有消失。）

### 4.2 8 字形：波纹的横截面

那波纹的截面长什么样？在 `evert` 里，球面被分成 `numStrips`（默认 8）条经度方向的"瓣"，绕着球一圈就是 8 道波纹。**沿着经度参数 $v$ 走过一条瓣时，膜画出的轨迹是一条"8 字形"曲线**。代码里负责生成它的函数就直接叫 `FigureEight`。

8 字形怎么来的？它其实是一条频率比 $2:1$ 的 **Lissajous（利萨茹）曲线**。取

$$
a(v)=\sin(4\pi v)\quad(\text{切向，1 圈内 2 个周期}),\qquad
b(v)=2\big(1-\cos 2\pi v\big)\quad(\text{法向，1 个周期}),
$$

当 $v$ 从 $0$ 走到 $1$：

- $b(v)=b(1-v)$（关于 $v=\tfrac12$ 对称），而 $a(1-v)=-a(v)$。要让曲线自己撞上自己，需要两个不同的 $v$ 给出相同的 $(a,b)$：$b$ 相等逼出 $v_2=1-v_1$，再要 $a$ 相等就得 $a(v_1)=0$，即 $v_1=\tfrac14$。
- 于是唯一的自交点在 $v=\tfrac14$ 与 $v=\tfrac34$，两者都落到 $(a,b)=(0,2)$。曲线在 $v=0,1$ 处回到 $(0,0)$ 闭合。

**横向频率是纵向的两倍**，这多出来的一次摆动，正好让曲线兜回来穿过自己一次——一个干净的 8 字。

> 顺带一提：8 字形是球面外翻里反复出现的主角。除了这里的波纹截面，当两片膜在赤道附近相互穿过时，赤道截面也会呈现 8 字形。它之所以好用，是因为一条 8 字可以让膜"出去—绕一圈—原路方向反过来回来"，方向翻转却不在任何一点停下（速度不为零），天然回避了尖点。

在代码里，波纹的"幅度"和"是否成形"分别由两个随纬度 $u$ 变化的插值函数 `FSInterp`（幅度）和 `FFInterp`（成形程度 `form`）控制。`form=0` 时波纹幅度为零、球面光滑；`form` 增大，8 字形逐渐"长出来"。两极附近幅度收敛到零，所以极点不会被波纹撕裂。

## 六、怎么"免费"精确算出法线：Jet 自动微分

到这里，公式都写好了，但渲染和验证都卡在同一件事上：**每个点都要它的法线 $\mathbf N=\mathbf P_u\times\mathbf P_v$**——既用来做光照着色，又用来检查 $\mathbf N\neq\mathbf 0$（确认没折痕）。

问题是，曲面公式 $\mathbf P(u,v)$ 是一大坨 $\sin,\cos,$ 幂、乘法、插值层层套出来的。手推它的偏导会疯掉；用有限差分 $\big(\mathbf P(u+\varepsilon)-\mathbf P(u)\big)/\varepsilon$ 又有数值噪声、极点附近尤其糟。

`evert` 的漂亮之处在于用了一种叫 **jet（自动微分）** 的技巧：**让每个数在参与运算时，随身带着自己的导数**，导数就顺着四则运算和链式法则**自动、精确地**算出来。

### 6.1 什么是 2-jet

在某一点 $(u_0,v_0)$，把一个函数 $f$ 打包成一个四元组，存它的值和几个偏导：

$$
x=\big(f,\ f_u,\ f_v,\ f_{uv}\big).
$$

（`evert` 实际用的是 **3-jet**，多存到二阶偏导 $f_{uu},f_{vv},\dots$，因为构造波纹的坐标架需要基础曲面的二阶信息。原理完全一样，为讲清楚我们用 2-jet。）

现在为这种"带导数的数"重新定义运算。**只要每个基本运算都按求导法则更新这些分量，那么任意用它们拼出来的复杂表达式，结果里自带的分量就是精确的偏导。**

### 6.2 加法与乘法

加法逐分量相加，无需赘述。乘法要用**乘积法则**。设 $h=x\cdot y$，$h$ 的各分量应当是：

$$
\begin{aligned}
h &= f g,\\
h_u &= f_u\,g + f\,g_u,\\
h_v &= f_v\,g + f\,g_v,\\
h_{uv} &= \frac{\partial}{\partial v}\big(f_u g + f g_u\big)
       = f_{uv}\,g + f_u\,g_v + f_v\,g_u + f\,g_{uv}.
\end{aligned}
$$

最后一行就是"混合偏导的乘积法则"。对照代码里的 `Mul`（`x.f`、`x.fu`… 就是这里的 $f,f_u,\dots$）：

```js
function tMul(x, y) {
  return TJ(
    x.f * y.f,                                             // h
    x.f * y.fu + x.fu * y.f,                               // h_u
    x.f * y.fv + x.fv * y.f,                               // h_v
    x.f * y.fuv + x.fu * y.fv + x.fv * y.fu + x.fuv * y.f  // h_uv
  );
}
```

一字不差。

### 6.3 链式法则：以 $\sin$ 为例

代码里的 `Sin` 约定先把参数乘以 $2\pi$（角度是"圈数"），即算 $g=\sin(2\pi f)$。记 $\phi=2\pi f$（于是 $\phi_u=2\pi f_u$ 等等），$s=\sin\phi_0$、$c=\cos\phi_0$。用链式法则一层层求：

$$
\begin{aligned}
g &= \sin\phi = s,\\
g_u &= \cos\phi\cdot \phi_u = c\,\phi_u,\\
g_v &= c\,\phi_v,\\
g_{uv} &= \frac{\partial}{\partial v}\big(c\,\phi_u\big)
       = \underbrace{-\sin\phi\cdot\phi_v}_{\partial c/\partial v}\,\phi_u + c\,\phi_{uv}
       = c\,\phi_{uv}-s\,\phi_u\phi_v.
\end{aligned}
$$

于是 $\sin$ 的 jet 是 $\big(s,\ c\phi_u,\ c\phi_v,\ c\phi_{uv}-s\phi_u\phi_v\big)$。对照代码：

```js
function tSin(x) {
  var t = tMulC(x, TAU), s = Math.sin(t.f), c = Math.cos(t.f);   // t = 2π·x
  return TJ(s, c * t.fu, c * t.fv, c * t.fuv - s * t.fu * t.fv);
}
```

同样一字不差。$\cos$、幂 `Pow`、插值 `Interpolate` 都照此办理。

### 6.4 从 jet 到法线

把这套"带导数的数"喂进整条曲面公式，出来的每个坐标 $x,y,z$ 就都是一个 jet，**自带**了 $x_u,x_v,\dots$。法线只要把这些一阶分量按叉积公式一拼：

```js
var nx = p.y.fu * p.z.fv - p.z.fu * p.y.fv;   // 正是 (P_u × P_v) 的三个分量
var ny = p.z.fu * p.x.fv - p.x.fu * p.z.fv;
var nz = p.x.fu * p.y.fv - p.y.fu * p.x.fv;
```

这正是第一节那个 $\mathbf N=\mathbf P_u\times\mathbf P_v$ 的分量式。**没有任何数值差分，法线是解析精确的。** 于是我们不但能正确打光，还能真的去检验"$\mathbf N$ 是否为零"——也就是**直接验证有没有折痕**。

## 七、所以，为什么全程没有折痕？

把线索收拢：

1. **判据**（第一节）：没有折痕 $\iff$ 处处 $\mathbf N=\mathbf P_u\times\mathbf P_v\neq\mathbf 0$。
2. **存在性**（第三节）：Smale 定理保证这样的正则同伦**存在**——障碍群 $\pi_2(SO(3))=0$。
3. **构造**（第四、五节）：波纹法把这条抽象路径**造**了出来。8 字形截面在两片膜相互穿过时提供横向余量，让切向量 $\mathbf P_u,\mathbf P_v$ 始终线性无关；即使基础曲面正把两极怼穿，法线也只是**连续地转向**，不塌成零。波纹在开头平滑长出、结尾平滑抹去，两端都是标准圆球，中间每一时刻都是浸入。
4. **验证**（第六节）：因为法线用 jet 精确算出，我们可以真的去查它。demo 里对 $t$ 从 0 到 1 采样、每点检查 $|\mathbf N|$：

   > 全程 **没有一个 NaN/Inf，法线全部是单位向量**；$t=0$ 与 $t=1$ 都是精确的单位球；赤道上取一点，$\mathbf{pos}\cdot\mathbf N$ 从 $t=0$ 的 $+1$ 连续变到 $t=1$ 的 $-1$——法线确实整体翻转了，且中途从未归零。

这就是"翻了面却没有折痕"的完整链条：**允许穿过自己**（浸入不必是嵌入），**只需守住切平面不塌**（$\mathbf N\neq0$），而**多一维带来的余量 + 波纹的巧妙安排**恰好能一直守得住。
